# Certify — Generator Sertifikat

Aplikasi web untuk membuat sertifikat dari data Excel dengan struktur kolom yang bebas.

## Menjalankan aplikasi

```bash
npm install
npm run dev:full
```

Lalu buka `http://localhost:5173`.

## Cara memakai

1. Impor Excel (`.xlsx` atau `.xls`) dengan header di baris pertama, misalnya `nama`, `kelas`, dan `tanggal`.
2. Pilih kolom yang mewakili nama penerima.
3. Tulis isi sertifikat dan sisipkan placeholder seperti `{{kelas}}` atau `{{tanggal}}`.
4. Pilih penerima untuk melihat pratinjau lalu unduh PDF-nya.

Template disimpan melalui server ke database `certificate_generator` pada MongoDB Atlas. Kredensial tetap berada di `.env` dan tidak pernah dikirim ke browser.

This template should help get you started developing with Vue 3 in Vite.

## Type Support for `.vue` Imports in TS

TypeScript cannot handle type information for `.vue` imports by default, so we replace the `tsc` CLI with `vue-tsc` for type checking. In editors, we need [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) to make the TypeScript language service aware of `.vue` types.

### Run End-to-End Tests with [Playwright](https://playwright.dev)

```sh

# When testing on CI, must build the project first
npm run build

# Runs the end-to-end tests
npm run test:e2e
# Runs the tests only on Chromium
npm run test:e2e -- --project=chromium
# Runs the tests of a specific file
```
